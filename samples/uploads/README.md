# Sample uploads (synthetic)

Made-up documents for testing the manual upload and analysis feature (Prompt 7). Every name, insurer, policy
number and address is invented. Generated by `npm run samples:make` (scripts/makeSampleUploads.ts); do not edit
by hand. They live here, NOT under fixtures/, so the fixtures and their hash snapshot never change.

| File | Use |
| ---- | --- |
| pol-s07-renewal.pdf | Attach to pol-s07 (its renewal is missing in the data source) |
| harbourview-expiring.pdf, harbourview-renewal.pdf | A new policy: Harbourview Bakery Ltd, public liability |
| hostile-expiring.pdf, hostile-renewal.pdf | Hostile text: instructions, delimiter strings, a formula-looking title, a 10,000-character paragraph |
| scanned-expiring.pdf | Image-only (no text layer): refused, no OCR |
| not-a-pdf.pdf | A text file with a .pdf name: refused |

Each `*.truth.json` is the answer key (expected ExtractedTerms) for one PDF, with that PDF's sha256. In fake mode
(`--fake-llm`) only these documents and the fixture documents can be analysed. `samples.sha256` lists every file.
